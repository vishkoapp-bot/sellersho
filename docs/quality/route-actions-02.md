Patterns are literal ServeMux registrations. Braced IDs describe suffix dispatch within a pattern, not additional registrations. **Any** means neither the listed dispatcher nor its delegate checks the HTTP method. A fallback receives requests not already matched by a preceding branch.

Actor attribution, object existence, and state validation are not tenant authorization. “Not shown” means no caller-to-tenant/object predicate was found at the cited boundary, not proof about DB policies.
