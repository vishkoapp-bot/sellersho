**Authorization key.** **Admin** means `RequireRoles("admin")`, which delegates to a capability check allowing `admin` or `super_admin`. **Super admin only** means `RequireCapabilities("super_admin")`, with no ordinary-admin alternative. Both require a valid Bearer JWT. With the capability repository wired, middleware reloads active capabilities from the database, filters `super_admin` through the eligible-mobile policy, and denies inactive or missing users. It returns 503 on auth-state lookup errors. Legacy role fallback applies only when the capability slice is nil, not when an authoritative refresh returns no capabilities. Neither wrapper binds the caller to a tenant or object. Sources: `main.go:222`, `auth_handlers.go:25–62,108–154`, `backend/internal/auth/jwt.go:29–42,72–115`, `backend/internal/repository/capability_repo.go:22–55,78–88`.
